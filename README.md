# osztv-feladatsorok
Felkészülés az Országos Szakmai Tanulmányi Versenyre szoftverfejlesztő és -tesztelő szakirányon

Tippek:

- csak akkor állj neki egy feladatsornak, ha kipihent vagy és koncentrált
- ne tömegesen töltsd ki a feladatsorokat, egy nap csak egyet
- miután kitöltöttél egyet, küld el a válaszaid kiértékelésre
- a kiértékelés után nézd át a (hibás) válaszaid, tanuld meg azt, amit eddig nem tudtál
- nézz át egy témakört, mielőtt egy tematikus feladatsort elkezdenél kitölteni
- próbáld kiszűrni a "hülyének" tűnő válaszlehetőségeket (általában ezek rossz válaszok)
- nem mindig a leghosszabb válasz a helyes!
